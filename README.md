# KPI Toà soạn – Báo Thanh Niên

Dashboard KPI pageview cho chuyên mục, Ban, văn phòng và phóng viên. Trang tĩnh, không thư viện ngoài.

- `index.html`, `assets/` — giao diện
- `data/periods.js` — danh sách kỳ KPI có dữ liệu; `data/kpi-YYYY.js` — dữ liệu từng kỳ (mở thẳng index.html cũng chạy)
- `#/admin` — nhập file Sản lượng + Video hằng tháng, nhập lại file KPI tổng, lưu lên GitHub

Chạy thử: mở thẳng index.html bằng trình duyệt
